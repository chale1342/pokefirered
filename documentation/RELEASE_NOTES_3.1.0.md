# Pokemon FireRed Enhanced 3.1.0

Version 3.1.0 adds supply vending machines to four remote rest stops where a
full Poke Mart is not nearby. They provide quick access to Poké Balls, Potions,
Antidotes, and Paralyze Heals at normal shop prices.

## Locations

- Route 4, beside the Pokemon Center near the Mt. Moon entrance
- Route 10, beside the Pokemon Center near the Rock Tunnel entrance
- Route 12, beside the fishing rest house
- Kindle Road, beside the Ember Spa entrance

The machines use a new Poké Ball-branded overworld design and vending-specific
dialogue. The purchase interface also preserves outdoor map colors while it is
open.

## Save compatibility

New games display every vending machine normally. Existing saves are supported,
but a machine may not appear on a map that was already stored in the save. Leave
and re-enter that map once to refresh its object list.
