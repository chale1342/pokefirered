# Changelog

This project uses semantic versioning.

## 3.1.0 - 2026-07-17

### Added

- Added supply vending machines at four remote rest stops:
  - Route 4, beside the Pokemon Center near Mt. Moon
  - Route 10, beside the Pokemon Center near Rock Tunnel
  - Route 12, beside the fishing rest house
  - Kindle Road, beside the Ember Spa entrance
- Added a new Poké Ball-branded vending-machine overworld sprite.
- Added a shared vending inventory with Poké Balls, Potions, Antidotes, and
  Paralyze Heals at standard shop prices.
- Added vending-specific prompts and follow-up dialogue.

### Fixed

- Preserved outdoor map palettes while the shop purchase screen is open.

## 3.0.0 - 2026-07-06

- Added the region map Pokemon area browser.
- Added starter-line overworld followers.
- Added options to skip the Controls Guide and Pikachu introduction.
- Fixed title-screen Charizard corruption and ENHANCED logo legibility.

## 2.0.0

- Added Physical/Special split icons.
- Added dual-mode Exp. Share behavior.
- Added FASTER text speed and AUTO SCROLL options.
- Expanded feature documentation.
